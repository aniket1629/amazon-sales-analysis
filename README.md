# Amazon Sales Analysis Dashboard

## 📌 Project Overview
This project presents an interactive Power BI dashboard built to analyze Amazon sales data and generate meaningful business insights. The dashboard helps identify sales trends, product performance, and category-wise analysis.

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX

## 📊 Dashboard Features
- Executive Summary with KPI Cards
- Monthly Sales Trend Analysis
- Product Performance Analysis
- Category-wise Sales Insights
- Interactive Filters and Slicers

## 📈 Key Insights
- Identified top-performing products based on sales.
- Analyzed sales trends over time.
- Compared category-wise performance.
- Created an interactive dashboard for easy business decision-making.
